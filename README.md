# Лабораторна робота №3

## Тема
Налаштування інтерфейсу користувача.

## Мета роботи
Ознайомитися з основними елементами керування Windows Forms та навчитися налаштовувати інтерфейс користувача мовою C#.

## Завдання
Створити програму з графічним інтерфейсом користувача та реалізувати роботу з основними компонентами Windows Forms.

## Виконання роботи
У середовищі Microsoft Visual Studio було створено Windows Forms застосунок мовою C#.

Під час виконання лабораторної роботи було використано компоненти Label та TextBox.

Компонент Label використовується для відображення текстової інформації на формі.

Компонент TextBox використовується для введення та редагування текстових даних користувачем.

У програмі було налаштовано властивості елементів керування та реалізовано роботу з текстовими полями.

Також було розглянуто основні методи компонентів:

- AppendText() — додавання тексту до поточного тексту;
- Clear() — очищення поля;
- Focus() — встановлення фокуса на компонент.

Під час виконання лабораторної роботи №3 було отримано практичні навички створення та налаштування інтерфейсу користувача у Windows Forms. Було розглянуто роботу з компонентами Label і TextBox, їх властивостями та основними методами.
